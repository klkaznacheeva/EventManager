# EventManager

EventManager — информационная система для организации и сопровождения мероприятий.

Проект разработан в рамках выпускной квалификационной работы. Система позволяет организаторам создавать и управлять мероприятиями и сессиями, назначать участников и координаторов, работать с чек-листами, собирать обратную связь и взаимодействовать с пользователями.

Проект состоит из backend-приложения на FastAPI и мобильного клиента на Flutter.

## Основные возможности

### Пользователи
- регистрация и авторизация;
- JWT-аутентификация;
- просмотр и редактирование профиля;
- смена пароля;
- загрузка аватара;
- поиск пользователей.

### Мероприятия
- создание, просмотр, редактирование и удаление мероприятий;
- публикация и завершение мероприятий;
- загрузка баннера;
- регистрация пользователя на мероприятие;
- просмотр участников;
- назначение организаторов и координаторов;
- управление статусами мероприятий.

### Сессии
- создание и редактирование сессий мероприятия;
- публикация и завершение сессий;
- присоединение участников;
- загрузка файлов;
- комментарии к сессиям.

### Чек-листы
- создание задач для мероприятия;
- назначение исполнителей;
- отслеживание выполнения задач.

### Обратная связь
- добавление и редактирование отзыва о мероприятии;
- получение отзывов участников;
- формирование сводной информации по обратной связи.

### Квизы
- создание квизов для сессий;
- управление активностью квиза;
- отправка ответов;
- просмотр статистики результатов.

### Дополнительные возможности
- уведомления;
- работа с файлами;
- взаимодействие между участниками;
- WebSocket-функциональность.

## Архитектура

Backend построен на основе REST API.

Основные слои приложения:

- `api` — REST endpoints;
- `services` — бизнес-логика;
- `models` — модели данных;
- `schemas` — модели запросов и ответов;
- `db` — работа с базой данных;
- `admin` — административный web-интерфейс;
- `tests` — автоматизированные тесты сервисного слоя.

В приложении реализованы REST API для работы с:

- авторизацией;
- пользователями;
- мероприятиями;
- сессиями;
- участниками;
- координаторами;
- чек-листами;

- файлами.
